《念奴嬌·赤壁懷古》 蘇軾 — 結構分析

主旨：借寫赤壁壯麗景致及追懷三國周瑜之英雄偉業，抒發年華老去、功業未成的感懷，並表現曠達超脫的人生態度。

段落 層次結構 原文對應 內容分析與抒情
上闋
（寫景與引出懷古）		 1. 寫長江總起 「大江東去，浪淘盡、千古風流人物。」 以長江浩蕩東流起興，導出千古英雄隨時間流逝而淹沒，奠定宏大深沉基調。
2. 點明古戰場位置 「故壘西邊，人道是、三國周郎赤壁。」 指出眼前景物乃傳聞中周瑜破曹之赤壁，將寫景轉入特定歷史空間。
3. 繪赤壁險峻壯景 「亂石穿空，驚濤拍岸，捲起千堆雪。江山如畫，一時多少豪傑。」 運用形色聲態寫赤壁懸崖怒濤之壯麗，並由「江山如畫」總括，自然過渡至英雄豪傑。
下闋
（懷古與自我感懷）		 4. 追懷周瑜形象 「遙想公瑾當年，小喬初嫁了，雄姿英發。羽扇綸巾，談笑間、檣櫓灰飛煙滅。」 描繪周瑜年少有為、娶得佳人、儀態儒雅（羽扇綸巾）且指揮若定、大破強敵的卓越功業。
5. 自身對比與感嘆 「故國神遊，多情應笑我，早生華髮。」 由周瑜之早達反襯自己年華已逝、早生白髮、功業未成，自嘲多情善感。
6. 人生如夢與超脫 「人間如夢，一尊還酹江月。」 領悟到千古英雄與世事皆如幻夢，遂灑酒祭月，寄情大自然，展現曠達自我解脫。

《青玉案·元夕》 辛棄疾 — 結構分析

主旨：通過渲染元宵節熱鬧喧騰、華麗繽紛的夜景與遊人，反襯「那人」的高潔孤獨，寄託詞人自甘寂寞、不肯同流合污的高尚情操。

段落 層次結構 原文對應 內容分析與抒情
上闋
（極力渲染燈市勝景）		 1. 燈火煙花盛況 「東風夜放花千樹。更吹落、星如雨。」 以比喻極言元宵夜滿城花燈絢麗多如千樹開花，煙花紛落如密集星雨。
2. 車馬來往繁華 「寶馬雕車香滿路。」 寫達官貴人、富貴人家乘名貴車馬觀燈，大道上充滿香氣，寫出盛世熱鬧景象。
3. 音樂燈舞熱烈 「鳳簫聲動，玉壺光轉，一夜魚龍舞。」 描繪簫聲四起、明月（玉壺）轉動、魚龍彩燈整夜翻騰歡跳的歡騰場面。
下闋
（寫遊人與尋覓那人）		 4. 觀燈婦女裝扮 「蛾兒雪柳黃金縷。笑語盈盈暗香去。」 寫眾多女子頭戴華麗飾物，歡聲笑語、帶著香氣經過，展現世俗女子爭妍鬥麗。
5. 尋覓與驀然發現 「眾裏尋他千百度。驀然回首，那人卻在、燈火闌珊處。」 千百次尋找不果，無意間回頭卻見「那人」獨處於燈火冷落處。以世俗繁華反襯「那人」孤高，寄託詞人志節。

《聲聲慢·秋情》 李清照 — 結構分析

主旨：通過描寫深秋黃昏時的孤獨處境與種種慘淡秋景，層層深入地抒發國破家亡、喪夫孤苦的無盡愁思。

段落 層次結構 原文對應 內容分析與抒情
上闋
（由內至外寫動作、氣候與心境）		 1. 疊字開篇總抒愁緒 「尋尋覓覓，冷冷清清，悽悽慘慘戚戚。」 連續使用14個疊字，從尋覓動作寫到環境冷清，再深入至內心悽慘悲戚，奠定極沉痛基調。
2. 氣候變化與淡酒難敵 「乍暖還寒時候，最難將息。三杯兩盞淡酒，怎敵他、晚來風急！」 寫秋季氣候忽冷忽熱難以調養，淡酒無法禦寒，更難敵急風，折射心靈極度脆弱。
3. 仰望雁過傷懷 「雁過也，正傷心，卻是舊時相識。」 抬頭見大雁飛過，聯想到昔日北方舊家與傳書舊事，如今人亡國破，更加傷感。
下闋
（俯察庭院與總結濃愁）		 4. 俯視黃花自況 「滿地黃花堆積，憔悴損，如今有誰堪摘？」 菊花凋零堆積，無人採摘，以花之枯萎憔悴比喻自身衰老孤苦。
5. 獨守寒窗與梧桐細雨 「守著窗兒，獨自怎生得黑！梧桐更兼細雨，到黃昏、點點滴滴。」 描繪獨坐窗前難熬至天黑，黃昏時雨打梧桐滴答作響，聲聲入耳，極力烘託淒涼。
6. 結句總括極致之愁 「這次第，怎一個愁字了得！」 直抒胸臆，指出眼前種種慘淡情境，豈是一個「愁」字所能包含盡淨，將愁情推向頂峰。

修辭及寫作手法說明

三首詞中運用的主要修辭格（比喻、借代、疊字等）與寫作手法（對比、襯托、借景抒情、虛實相生）。

一 修辭手法解析

1. 明喻 / 暗喻 / 借喻（比喻） 核心修辭

• 「捲起千堆雪」：以白雪比喻驚濤拍岸激起的白色浪花（《念奴嬌》）。
• 「花千樹」、「星如雨」：以千樹花開比喻繁多燈火，以密集雨點比喻落下的煙花（《青玉案》）。
• 「玉壺光轉」：以晶瑩的玉壺比喻明月（《青玉案》）。
• 「人間如夢」：將短暫虛幻的人生意境比作幻夢（《念奴嬌》）。

2. 借代 特徵代本體

• 「羽扇綸巾」：以羽扇和青絲頭巾代指裝束儒雅的周瑜（《念奴嬌》）。
• 「檣櫓」：以船桅和船槳代指曹軍的所有戰船（《念奴嬌》）。
• 「蛾兒雪柳黃金縷」：以各種婦女頭飾代指盛裝打扮的觀燈婦女（《青玉案》）。
• 「黃花」：以黃花代指菊花（《聲聲慢》）。

3. 疊字（疊詞） 音韻與情感

• 「尋尋覓覓，冷冷清清，悽悽慘慘戚戚」：開篇連用十四個疊字，音節流轉鏗鏘，由外在動作層層推進入內心感受，極寫孤寂悲慘（《聲聲慢》）。
• 「點點滴滴」：模擬細雨打在梧桐葉上的連續聲音，增添淒涼感受（《聲聲慢》）。
• 「笑語盈盈」：描繪觀燈女子歡笑喧鬧的熱鬧模樣（《青玉案》）。

4. 誇張與反問 強化語氣

• 夸張「亂石穿空」、「寶馬雕車香滿路」：極言山崖之高聳與馬車經過後香氣瀰漫全路。
• 反問「如今有誰堪摘？」：以強烈反問指出菊花凋零且自身憔悴，根本無心思摘花（《聲聲慢》）。

二 寫作手法解析

1. 對比與襯托（反襯） 章法焦點

• 英雄與自我對比：以周瑜的少壯有為、英姿勃發，反襯詞人自身的年華老去、仕途失意（《念奴嬌》）。
• 以熱鬧襯托孤高（反襯）：以元宵夜的滿城燈火、車水馬龍、爭妍婦女，反襯「那人」獨處燈火闌珊處的高潔孤傲（《青玉案》）。

2. 借景抒情 / 觸景生情 情景交融

• 《念奴嬌》：借滾滾東流的長江與雄偉赤壁景色，抒發人生短暫、千古英雄皆被時間淘盡的感嘆。
• 《聲聲慢》：借晚風、過雁、滿地黃花、梧桐細雨等深秋慘淡景物，層層渲染喪夫國破後的無邊孤苦與愁思。

3. 虛實相生與寄託 意境昇華

• 虛實結合：眼前的赤壁長江景象為「實」，想像周瑜當年赤壁之戰的雄姿與場面為「虛」（《念奴嬌》）。
• 託物言志（別有寄託）：「燈火闌珊處的那人」不僅是佳人，更是詞人理想人格與不肯屈從世俗政局的自我投射（《青玉案》）。

4. 多感官摹寫 視覺·聽覺·嗅覺

• 視覺：「驚濤拍岸，捲起千堆雪」（《念奴嬌》）、「花千樹」、「星如雨」（《青玉案》）。
• 聽覺：「鳳簫聲動」（《青玉案》）、「點點滴滴」（《聲聲慢》）。
• 嗅覺：「寶馬雕車香滿路」、「暗香去」（《青玉案》）。
